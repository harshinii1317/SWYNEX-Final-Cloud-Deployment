SWYNEX Task 4: Final Cloud Deployment

1. Project Overview

This case study combines cloud architecture, website deployment, monitoring, cost awareness, and security practices. The project demonstrates how a simple cloud computing guide website can be documented, deployed, and maintained.

2. Cloud Architecture

The website uses a simple static web architecture.

- Frontend: HTML, CSS, and JavaScript.
- Version Control: GitHub stores the source code and documentation.
- Cloud Hosting: Netlify hosts the static website and provides a public URL.
- Users: Visitors access the website through a web browser.

Architecture Flow

User → Web Browser → Netlify Hosting → HTML, CSS, and JavaScript Files

GitHub stores the source code and connects to the deployment workflow.

3. Deployment Process

1. Created the website using HTML, CSS, and JavaScript.
2. Uploaded the project files to a public GitHub repository.
3. Connected the repository to Netlify.
4. Deployed the website and received a public URL.
5. Tested the website and its interactive features.

Live Website: https://cloud-computing-guide.netlify.app/

Task 2 Repository: https://github.com/harshinii1317/SWYNEX-Basic-Cloud-Deployment

4. Monitoring Plan

Basic monitoring helps identify availability and functionality issues.

- Check whether the website loads correctly.
- Review deployment logs when an error occurs.
- Test links and interactive buttons.
- Check the website after making changes.

Simple Alert Idea

If a website availability check fails, notify the project owner so they can investigate the issue.

5. Cost Awareness

- Use free hosting options when suitable.
- Review service usage and billing information.
- Remove unused resources.
- Set budget alerts when supported by the provider.
- Avoid enabling paid services unnecessarily.

6. Security Checklist

- Protect GitHub and hosting accounts with strong passwords and multi-factor authentication.
- Review repository and deployment permissions.
- Never upload passwords, API keys, or secret tokens to GitHub.
- Keep project dependencies updated.
- Use HTTPS for public website access.

7. Lessons Learned

Through these tasks, I learned about cloud architecture documentation, GitHub version control, static website deployment, basic monitoring, cost awareness, and cloud security practices. I also gained experience documenting a project and sharing technical work professionally.

8. Conclusion

This case study brings together the main stages of a simple cloud deployment project, from organizing source code to hosting a website and documenting monitoring, cost, and security practices.
